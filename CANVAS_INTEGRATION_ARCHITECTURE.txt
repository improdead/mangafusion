Backend Service: CanvasService
════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────────┐
│                         CANVAS SERVICE METHODS                           │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  async saveCanvas(pageId, drawingData, options):                         │
│    1. Deserialize and validate strokes                                   │
│    2. Render strokes to PNG using Sharp/Canvas                           │
│    3. Composite with original image (if requested)                       │
│    4. Generate thumbnail                                                 │
│    5. Upload to Supabase:                                                │
│       - canvas/{pageId}_v{n}.png (pure drawing)                          │
│       - overlay/{pageId}_v{n}.png (composite)                            │
│       - thumbnail/{pageId}.png (preview)                                 │
│    6. Save to Canvas table in DB                                         │
│    7. Return: {canvasUrl, overlayedImageUrl, version}                    │
│                                                                          │
│  async getCanvas(pageId):                                                │
│    1. Query Canvas table for latest version                              │
│    2. Deserialize strokesData (from BYTEA)                               │
│    3. Return: {strokes, canvasWidth, canvasHeight, ...}                  │
│                                                                          │
│  async renderCanvasImage(data):                                          │
│    1. Create image buffer (1024x1536 or custom size)                     │
│    2. For each stroke:                                                   │
│       - Set color, width, opacity                                        │
│       - Draw path from points array                                      │
│    3. Return PNG Buffer                                                  │
│                                                                          │
│  async compositeImages(originalUrl, canvasImage):                        │
│    1. Fetch original image from Supabase URL                             │
│    2. Load both images using Sharp                                       │
│    3. Composite: canvasImage on top of original                          │
│    4. Return merged PNG Buffer                                           │
│                                                                          │
│  async finalizeCanvas(pageId, options):                                  │
│    1. Get canvas for pageId                                              │
│    2. Get current page imageUrl                                          │
│    3. If mergeMode === 'overlay':                                        │
│       - Composite canvas with original                                   │
│    4. Upload final composite to Supabase                                 │
│    5. Update Page record:                                                │
│       - Page.imageUrl = final composite URL                              │
│       - Page.version += 1                                                │
│       - Page.canvasId = canvas.id                                        │
│       - Page.canvasVersion = canvas.version                              │
│    6. Return: {imageUrl, compositeUrl}                                   │
│                                                                          │
│  async clearCanvas(pageId):                                              │
│    1. Delete all strokes for pageId                                      │
│    2. Mark as deleted in Canvas table                                    │
│    3. Clean up Supabase files                                            │
│                                                                          │
│  async getCanvasVersions(pageId):                                        │
│    1. Query Canvas table for all versions of pageId                      │
│    2. Return: [{version, thumbnail, createdAt, strokeCount}, ...]        │
│                                                                          │
│  async restoreCanvasVersion(canvasId, version):                          │
│    1. Query CanvasHistory for canvasId:version                           │
│    2. Restore strokes from historical snapshot                           │
│    3. Update Canvas.isLatest flags                                       │
│    4. Re-render and re-upload images                                     │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

NEW TABLE: Canvas
────────────────────────────────────────────────────────────────────────────

  id (UUID) PRIMARY KEY
      └─ Unique identifier for each canvas

  pageId (UUID) UNIQUE, FK → Page.id ON DELETE CASCADE
      └─ One canvas per page

  episodeId (UUID) FK → Episode.id ON DELETE CASCADE
      └─ Track which episode this canvas belongs to

  strokesData (BYTEA)
      └─ Compressed stroke array (MessagePack/Protobuf)
      └─ Contains all drawing data needed for undo/redo

  strokeCount (INT)
      └─ Denormalized for quick stats queries

  canvasWidth (INT) DEFAULT 1024
  canvasHeight (INT) DEFAULT 1536
      └─ Canvas dimensions (standard manga page size)

  canvasImageUrl (TEXT)
      └─ URL to pure drawing (before compositing)
      └─ https://supabase.../canvas/{pageId}_v{n}.png

  overlayImageUrl (TEXT)
      └─ URL to composite image (original + canvas)
      └─ https://supabase.../overlay/{pageId}_v{n}.png

  thumbnail (TEXT)
      └─ Small preview for version browser
      └─ https://supabase.../thumbnail/{pageId}.png

  version (INT) DEFAULT 1
      └─ Canvas version counter (increments on save)

  isLatest (BOOLEAN) DEFAULT true
      └─ Flag for quick lookup of current version

  createdAt (TIMESTAMP) DEFAULT NOW()
  modifiedAt (TIMESTAMP) DEFAULT NOW()
      └─ Track creation and last modification

  Indexes:
    ├─ PRIMARY KEY (id)
    ├─ UNIQUE (pageId)
    ├─ INDEX (episodeId)
    └─ INDEX (createdAt)


MODIFIED TABLE: Page
────────────────────────────────────────────────────────────────────────────

  EXISTING COLUMNS:
    ├─ id, episodeId, pageNumber, status, imageUrl, ...
    └─ overlays (JSON) - existing overlay data

  NEW COLUMNS:
    ├─ canvasId (UUID) FK → Canvas.id ON DELETE SET NULL
    │  └─ Reference to associated canvas

    ├─ canvasVersion (INT) DEFAULT 0
    │  └─ Denormalized canvas version for quick access

    ├─ lastCanvasEdit (TIMESTAMP) NULLABLE
    │  └─ When canvas was last modified

    ├─ canvasEnabled (BOOLEAN) DEFAULT false
    │  └─ Whether canvas is active for this page

    └─ Indexes:
       ├─ INDEX (canvasId)
       └─ INDEX (canvasEnabled)


OPTIONAL TABLE: CanvasHistory
────────────────────────────────────────────────────────────────────────────

  id (UUID) PRIMARY KEY
  canvasId (UUID) FK → Canvas.id ON DELETE CASCADE
  version (INT)
  strokeCount (INT)
  thumbnail (TEXT)
  createdAt (TIMESTAMP) DEFAULT NOW()

  UNIQUE (canvasId, version)
  INDEX (canvasId, version DESC)

│   ├─ Serialize strokes to JSON
│   └─ Send: {strokes, canvasWidth, canvasHeight, ...}
    ↓
PagesController.saveCanvas()
    ├─ Validate request
    └─ Call CanvasService.saveCanvas()
         ↓
    CanvasService.saveCanvas()
         ├─ 1. Deserialize strokes
         ├─ 2. Validate stroke data
         ├─ 3. renderCanvasImage(strokes)
         │    └─ Use Sharp/Canvas to draw all strokes
         ├─ 4. compositeImages(original, canvasBuffer)
         │    └─ Blend canvas with original image
         ├─ 5. generateThumbnail()
         ├─ 6. StorageService.uploadImage() × 3
         │    ├─ Upload pure drawing
         │    ├─ Upload composite
         │    └─ Upload thumbnail
         ├─ 7. Compress strokes: MessagePack
         ├─ 8. Save to Canvas table:
         │    ├─ INSERT if new
         │    └─ UPDATE if exists
         └─ Return URLs & metadata
             ↓
    Response:
    ├─ canvasUrl: URL of pure drawing
    ├─ overlayedImageUrl: URL of composite
    ├─ version: incremented
    └─ modifiedAt: timestamp
             ↓
Frontend Updates UI
    ├─ Show composite preview
    ├─ Update version badge
    ├─ Show "saved" indicator
    └─ Continue accepting input

│                   TECH STACK FOR CANVAS FEATURE                            │
└─────────────────────────────────────────────────────────────────────────────┘

Frontend:
  ├─ Fabric.js (v5+)
  │  └─ Rich drawing capabilities, broad browser support
  │  └─ Features: free drawing, undo/redo, layers, animations
  │
  ├─ React Hook: Custom useCanvas() for state management
  │  └─ Manage strokes, undo/redo stack, auto-save
  │
  └─ Tailwind CSS for UI components

Backend (Node.js):
  ├─ Sharp (image processing)
  │  └─ Fast, native image rendering and compositing
  │  └─ Support: resize, overlay, blend modes
  │
  ├─ MessagePack (stroke compression)
  │  └─ ~30% smaller than JSON
  │  └─ Better performance for large stroke arrays
  │
  └─ Prisma (ORM for Canvas table)
      └─ Query optimization, transaction support

Storage:
  └─ Supabase (S3-compatible bucket)
      └─ Public URLs, fast delivery, CDN support
