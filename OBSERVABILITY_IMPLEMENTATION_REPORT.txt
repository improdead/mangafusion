## MONITORING SETUP INSTRUCTIONS
================================================================================

### Option 1: Sentry (Error Tracking)

  1. Sign up at https://sentry.io
  2. Create project: "MangaFusion Backend" (Node.js)
  3. Create project: "MangaFusion Frontend" (Next.js) [optional]
  4. Copy DSN from project settings
  5. Add to .env:
     SENTRY_DSN=your-backend-dsn
     NEXT_PUBLIC_SENTRY_DSN=your-frontend-dsn
  6. Restart application
  
  Status: Ready to use ✅

### Option 2: Jaeger (Local Tracing)

  1. Run with Docker:
     docker run -d --name jaeger \
       -p 16686:16686 -p 4318:4318 \
       jaegertracing/all-in-one:latest
  
  2. Add to .env:
     OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318/v1/traces
  
  3. Restart application
  4. View traces: http://localhost:16686
  
  Status: Ready to use ✅

### Option 3: Honeycomb (Cloud Tracing)

  1. Sign up at https://honeycomb.io
  2. Get API key from settings
  3. Add to .env:
     OTEL_EXPORTER_OTLP_ENDPOINT=https://api.honeycomb.io/v1/traces
     OTEL_EXPORTER_OTLP_HEADERS='{"x-honeycomb-team":"API_KEY"}'
  
  4. Restart application
  
  Status: Ready to use ✅

### Option 4: Grafana Cloud (Cloud Tracing)

  1. Sign up for Grafana Cloud
  2. Get OTLP credentials
  3. Add to .env:
     OTEL_EXPORTER_OTLP_ENDPOINT=https://otlp-gateway...grafana.net/otlp
     OTEL_EXPORTER_OTLP_HEADERS='{"Authorization":"Basic base64-creds"}'
  
  4. Restart application
  
  Status: Ready to use ✅
